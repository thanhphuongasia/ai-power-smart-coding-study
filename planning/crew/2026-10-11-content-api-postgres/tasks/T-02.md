# T-02: content.json (xuất từ seed + judge) + load_content.py (backend)

- **ID · tier · model**: T-02 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Một file nguồn soạn nội dung `backend/content/content.json` và lệnh nạp nó vào Postgres (thay toàn bộ, một transaction).
- **Owned files**: `backend/content/content.json` (mới), `backend/app/load_content.py` (mới), `backend/tests/test_load_content.py` (mới)
- **Forbidden files**: mọi file khác (đặc biệt `backend/app/tables.py`, `db.py`, `main.py`, `exercises.json` — chỉ đọc; `mobile/**` chỉ đọc). File tạm dùng để xuất (vd một Dart test tạm) phải XOÁ trước khi báo xong.
- **Acceptance criteria**:
  1. `content.json` đúng shape PLAN.md "Hợp đồng `GET /content`" + mỗi exercise có `judge: {solution, cases}` lấy NGUYÊN VĂN từ `backend/app/exercises.json`. Nội dung (themes/topics/files/exercises/blocks/challenge) xuất MÁY từ seed Dart bằng `Content(version:'seed', themes: seedThemes).toJson()` (mobile/lib/domain/content.dart) — không gõ tay. Ghi rõ cách đã xuất trong báo cáo. Thứ tự giữ như seed. JSON định dạng `indent=2, ensure_ascii=False`, có key `version` = `"source"` (giá trị thật do loader tính).
  2. `load_content.py`: `load_content(session, data: dict) -> str` (trả version) và CLI `python -m app.load_content [path]` (mặc định `content/content.json`, dùng `SessionLocal` của app/db.py, in version). Validate trước khi ghi: id duy nhất theo từng loại; mỗi `exercise_ids` tồn tại; label ô duy nhất trong bài; mỗi bài có judge.solution + ≥1 case; sai → `ValueError` nêu rõ chỗ sai, DB không đổi.
  3. Ghi: xoá toàn bộ bảng nội dung rồi chèn lại theo `position`, cùng một transaction (INV-06). `version` = `"sha256:" + sha256(json.dumps(public, sort_keys=True, ensure_ascii=False, separators=(",", ":")))` với `public` = data bỏ `judge` và bỏ `version`; lưu `content_meta(key='version')`. Hàm thuần `public_payload(data) -> dict` export để T-06 dùng chung.
  4. Test (fixture `db_session` ở tests/conftest.py): nạp file thật → đúng số dòng (3 theme, 5 bài, split-chunks có 2 dòng file_exercises); nạp 2 lần → cùng version, cùng số dòng; nạp data bỏ 1 bài → bài đó biến mất; data lỗi (id trùng, exercise_ids lạ, thiếu judge) → ValueError và DB giữ dữ liệu cũ; judge.solution của từng bài trong content.json == `solution` trong exercises.json.
- **Validation command**: `cd backend && .venv/bin/python -m pytest -q tests/test_load_content.py`
- **Evidence command**: `git status --porcelain -- backend/ mobile/`
- **Thứ tự thực hiện**: (1) loader + validate + test với data nhỏ; (2) xuất content.json; (3) test với file thật.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`.
