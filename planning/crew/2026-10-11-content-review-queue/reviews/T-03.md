  - `:36 from app.load_content import validation_errors` (hàm kiểm, không ghi).
  - Đã bỏ import `load_content`, `lock_content`, `export_content`, `DataError`.
- **Đọc/ghi qua draft.**
  - `_read` dùng `review.draft_content` (`:91`).
  - `_write` lấy `before = review.draft_content` (`:99`) và `base = admin_version(before)`, nên base = hash(draft).
  - Ghi bằng `review.submit(session, base, after, author)` (`:114`). `submit` tự `lock_content` rồi so base với hash(draft) trong khoá (`review.py:366-371`).
  - Điều này đúng yêu cầu "write = review.submit trong khoá, base = hash(draft)".
- **Lỗi.**
  - `VersionConflict` → `rollback` + ToolError thông điệp tiếng Việt, không lộ nội bộ (`:115-117`).
  - `ContentOpError` → ToolError (`:102-103`, `:93-94`).
  - Validation lỗi → ToolError có giới hạn `MAX_ERRORS` (`:107-108`).
  - `dry_run` trả về trước `submit` nên không ghi pending (`:109-110`). Test assert `pending_rows == []`.
  - Bỏ `DataError`: an toàn, vì `content_rules.py:271-305` giới hạn id ≤100 (khớp `String(100)` của `item_id`), và `load_content.py:158` chặn NUL (JSONB). `author` là `Text`.

### Findings
- **Minor-1: thiếu hướng dẫn ở 5/8 docstring.** `mcp_server.py:198, 205, 214, 221, 226`.
  - Bằng chứng: 5 docstring như `"""Sửa project; chỉ các field name, description, tags, diagram."""` không nhắc hàng chờ.
  - Tác tác: LLM thường dựa vào mô tả từng tool nên có thể không báo user "cần admin duyệt". Tuy vậy `INSTRUCTIONS` và message trả về đã nói rõ, nên rủi ro thấp.
  - Cách sửa: không cần lặp từng docstring. Thông điệp trả về đã đủ, có thể bỏ luôn 3 câu đã thêm cho nhất quán; hoặc thêm cùng một hằng `_QUEUE_NOTE` cho cả 8 tool.
  - Test cần bổ sung: không bắt buộc.
- **Minor-2: acceptance "tạo file rồi tạo bài trong file đó" chưa có test.** `tests/test_mcp.py:254-266`.
  - Bằng chứng: chain test chỉ tạo project → module → sub-module → file, không gọi `create_lesson` vào `zz-file`.
  - Tác động: ca có phụ thuộc cha-con với bài pending trong file pending (`merge_pending`/`apply_change` kind exercise) chưa được chứng minh qua MCP. Đọc code thì có vẻ chạy đúng, nhưng chưa có test chứng minh.
  - Cách sửa: thêm một `create_lesson(file_id="zz-file", ...)` sau chain, rồi assert `get_lesson` đọc được và có row pending kind=exercise.
- **Minor-3: chưa có test `update_*` trên mục đã live.** Các test chỉ tạo mới hoặc sửa bài đang pending; không kiểm action `update` có `before` là mục live.
  - Cách sửa: thêm `update_project`/`update_module` trên mục live rồi assert row pending `action == "update"` và `/content` không đổi.
- **Minor-4: dòng quá dài / lặp.** `mcp_server.py:55` (INSTRUCTIONS một dòng rất dài), `:110`, `:121`. Chỉ ảnh hưởng đọc code.
