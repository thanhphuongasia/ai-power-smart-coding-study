# T-06: Tiến độ mới (passed/drafts theo ô/solutionViewed) + quy tắc khoá bài (mobile)

- **ID · tier · model**: T-06 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Một nguồn "đã xong" (`passed`), draft/hint theo ô, ghi nhận xem lời giải, quy tắc khoá bài trong `progression.dart`.
- **Owned files**: `mobile/lib/features/exercise/session_controller.dart`, `mobile/lib/features/exercise/session_providers.dart`, `mobile/lib/domain/progression.dart` (mới), `mobile/test/session_controller_test.dart`, `mobile/test/progression_test.dart` (mới), `mobile/lib/data/seed.dart` (CHỈ để xoá `seedCompletedBlocks`)
- **Forbidden files**: `backend/**`, `planning/**`, mọi file mobile khác.
- **Acceptance criteria**:
  1. Đúng `tasks/_shared.md` mục Progress. Khởi tạo từ `seedPassedExercises` + `seedDrafts`. `completedBlocks` chỉ suy ra từ `passed` (getter hoặc tương đương — KHÔNG có field lưu riêng có thể lệch). Test: `markPassed` ⇒ `completedBlocks == exercise.blocks.length`.
  2. `inProgressExerciseProvider` = bài đầu tiên `!passed && có draft không rỗng` (INV-09). Thêm `exerciseUnlockedProvider` (family theo id) dùng `isExerciseUnlocked` (INV-08).
  3. `progression.dart`: `isExerciseUnlocked` (bài đầu file luôn mở; bài k mở khi bài k-1 trong CÙNG `CodeFile` đã passed; bài nằm ở nhiều file mở nếu mở ở bất kỳ file nào) và `nextExerciseAfter` (bài kế trong cùng CodeFile đầu tiên chứa nó, null nếu cuối). Test bằng seed thật: overlap-chunks khoá khi split-chunks chưa pass, mở khi pass; split-chunks luôn mở; next của split-chunks = overlap-chunks.
  4. Code cũ (CellScreen/BlockListScreen, review, stats) PHẢI còn compile: giữ API cũ mà chúng gọi dưới dạng `@Deprecated('Xoá ở T-10')` nếu cần, map sang API mới (vd `markBlockPassed` ở block cuối ⇒ `markPassed`). Liệt kê các API deprecated trong báo cáo.
  5. `knownIdentifiersFor` vẫn ra tên hàm + tham số (template giờ giữ dòng def).
  6. `activityProvider.record()` được gọi khi `markPassed` (giữ hành vi heatmap/streak).
- **Validation command**: `cd mobile && flutter test test/session_controller_test.dart test/progression_test.dart && flutter analyze`
- **Evidence command**: `git status --porcelain -- mobile/lib/features/exercise/session_controller.dart mobile/lib/features/exercise/session_providers.dart mobile/lib/domain/progression.dart mobile/test/session_controller_test.dart mobile/test/progression_test.dart mobile/lib/data/seed.dart`
- **Thứ tự thực hiện**: (1) progression.dart + test; (2) ExerciseProgress/ProgressController + test; (3) giữ code cũ compile, `flutter analyze`.
