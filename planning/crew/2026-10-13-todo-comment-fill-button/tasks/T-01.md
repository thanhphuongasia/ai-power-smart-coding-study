# T-01: Ô TODO trống hiện `# TODO <nhãn> — <tiêu đề>` + nút "Điền code"

ID · tier · model: T-01 · T2 · crew-impl-standard (balanced = sonnet)

## Objective

Ô TODO rỗng trong `CodeTab` (màn làm bài học viên, tái dùng ở màn Xem trước admin qua
`ExerciseScreen(preview: true)`) hiện dòng comment thật `# TODO <nhãn> — <tiêu đề>` thay cho
placeholder mờ generic hiện tại, kèm nút "✏️ Điền code" rõ ràng. Bấm nút mở đúng
`CellEditorPage` hiện có (không tạo box nhập inline mới, không đổi kiến trúc). Ô đã có code,
và toàn bộ logic khoá ô/accordion/markPassed/lưu draft — không đổi.

## Bối cảnh code hiện tại (đã đọc)

- `code_tab.dart` dòng ~439–551 (`_todoCell`): render ô TODO — nếu không mở (`_open != label`)
  và không lỗi → `_CollapsedCell`; nếu mở → header (LabelTag, title, where, done-check, chevron)
  + `_CodePreview` trong khung có border đỏ khi lỗi/rỗng.
- `code_tab.dart` dòng ~739–796 (`_CodePreview`): nhận `code` + `onTap`. Khi `code.trim().isEmpty`
  → hiện `Text('# chạm để viết code', style: italic, color: p.inkMuted)`. Khi có code → syntax
  highlight qua `hl.highlight.parse(code, language: 'python')` + `_codeStyles(p)`. Toàn bộ Row
  (line numbers + text + icon `open_in_full`) nằm trong `InkWell(onTap: onTap, ...)`.
- `_codeStyles(p)` (dòng ~727–735) đã có style `'comment': TextStyle(color: p.outline,
  fontStyle: FontStyle.italic)` — dùng tông màu NÀY cho dòng `# TODO`, không dùng `p.inkMuted`
  generic như placeholder cũ.
- `_LockedCell` (dòng ~660–725) là ví dụ cách render code có sẵn + tag "🔒 có sẵn" — tham khảo
  cách dùng `AppText.code`/`_codeStyles` nhưng KHÔNG cần đổi widget này.
- `Block.title` (mobile/lib/domain/models.dart dòng ~544) đã có sẵn, ngắn (vd "Chuyến bay đã
  đầy chưa") — dùng thẳng, không thêm field.
- Test hiện có (`mobile/test/code_tab_test.dart`) tap mở editor qua
  `find.byKey(Key('cell-$label-field'))` (dòng 113, helper `_openEditor`) — PHẢI giữ đúng Key
  này trên widget tappable hiện có (ví dụ giữ nguyên `InkWell` bọc ngoài `_CodePreview`, Key gắn
  trên đúng chỗ như cũ). Không có test nào assert literal text `'# chạm để viết code'` (đã
  grep xác nhận) nên đổi text không vỡ test cũ — nhưng PHẢI chạy lại toàn bộ file test để chắc.

## Việc cần làm

1. Sửa `_CodePreview`: thêm tham số `label` và `title` (truyền từ `_todoCell` khi gọi, lấy từ
   `Block b` đang có sẵn trong scope — `b.label`, `b.title`). Khi `code` rỗng:
   - Thay dòng text hiện tại bằng 2 phần: dòng `# TODO $label — $title` style comment
     (`p.outline`, italic, dùng `AppText.code`/mono như code khác trong file), và một nút
     "✏️ Điền code" bên dưới (style nổi bật — dùng `p.primary`/`p.onPrimary`, tham khảo
     `PrimaryButton` trong `mobile/lib/shared/widgets.dart` nếu phù hợp kích thước, hoặc
     `ElevatedButton`/`FilledButton` inline cũng được, miễn nhất quán style file này), `onPressed`
     gọi lại đúng `onTap` đã truyền vào.
   - Giữ `InkWell`/`Key('cell-$label-field')` bọc ngoài như cũ để tap cả vùng vẫn hoạt động
     (không bắt buộc bỏ, nút chỉ là lối vào RÕ RÀNG hơn, không thay thế toàn bộ vùng tap).
   - Icon `open_in_full` ở cuối: có thể bỏ khi rỗng (không còn ý nghĩa "mở xem code đã viết"),
     giữ khi có code — tuỳ chọn, ghi rõ quyết định trong PR nếu bỏ.
2. Khi `code` KHÔNG rỗng: không đổi gì so với hiện tại.
3. Cập nhật nơi gọi `_CodePreview` trong `_todoCell` để truyền `b.label`, `b.title`.
4. Chạy `cd mobile && flutter test test/code_tab_test.dart` — xác nhận TOÀN BỘ test cũ pass
   trước khi viết thêm gì.
5. Thêm ≥1 test mới trong `code_tab_test.dart`: ô rỗng hiện đúng text `# TODO <nhãn> —
   <tiêu đề>` (lấy tiêu đề thật từ `testContent.exerciseById(_id)` — exercise fixture đã có
   trong file, xem `_ex`/`_id` ở đầu file), và nút "Điền code" bấm vào mở đúng
   `CellEditorPage` (có thể verify qua các Key đã có như `'editor-title'` sau khi tap, theo
   đúng pattern `_openEditor` helper hiện dùng).

## Acceptance criteria

1. Ô rỗng hiện đúng `# TODO <nhãn> — <tiêu đề block>` kiểu comment (không phải text mờ generic
   cũ) + nút "Điền code" rõ ràng.
2. Bấm nút mở đúng `CellEditorPage` hiện có — không có box nhập inline mới, không điều hướng
   route khác.
3. Ô đã có code: hiển thị KHÔNG đổi so với trước khi sửa.
4. `flutter test test/code_tab_test.dart` — 100% test cũ + mới đều pass.
5. `flutter analyze lib/features/exercise/code_tab.dart` không phát sinh lỗi/warning mới.
