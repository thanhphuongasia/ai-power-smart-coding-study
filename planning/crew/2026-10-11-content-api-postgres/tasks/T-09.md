# T-09: Xoá nội dung khỏi app, test dùng fixture từ content.json, contract test (mobile)

- **ID · tier · model**: T-09 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: App không còn chứa nội dung học; test đọc nội dung thật từ `backend/content/content.json`; luật hợp đồng (INV-04/05) khoá trên file đó.
- **Owned files**: `mobile/lib/data/seed.dart` → đổi thành `mobile/lib/data/demo_seed.dart` (chỉ giữ dữ liệu demo tiến độ: seedPassedExercises, seedDrafts, seedActivityDaysAgo, seedReviewDueInDays, seedPendingContent); `mobile/lib/data/content_providers.dart` (mặc định `contentIndexProvider` ném `UnimplementedError('override contentIndexProvider')`); `mobile/lib/features/exercise/session_controller.dart` (CHỈ: bỏ qua id demo không có trong content thay vì ném StateError); `mobile/test/support/content_fixture.dart` (mới: `final testContent = Content.fromJson(jsonDecode(File('../backend/content/content.json').readAsStringSync()))` + `contentOverrides`); `mobile/test/content_contract_test.dart` (mới, thay `judge_contract_test.dart` + luật nội dung của `seed_test.dart`, xoá 2 file đó); mọi test đang import seed hoặc dựng ProviderScope/ProviderContainer (thêm override fixture); các file lib còn import `seed.dart` → đổi import sang `demo_seed.dart`.
- **Forbidden files**: `backend/**` (chỉ đọc content.json), `planning/**`.
- **Acceptance criteria**:
  1. `grep -rn "seedThemes\|splitChunksExercise" mobile/lib` rỗng; `mobile/lib/data/seed.dart` không còn tồn tại.
  2. `content_contract_test.dart` trên content.json: (a) INV-05: mỗi ô có đúng một marker `# TODO <label>`, thụt = 4 × indent_level, không marker thừa; (b) INV-04: `mergeCells(exercise, {label: accepted_answers.first})` == `judge.solution` từng ký tự; (c) mỗi `exercise_ids` tồn tại; (d) Content.fromJson parse được file (bỏ qua key judge/version source); (e) giữ các luật nội dung cũ của seed_test còn ý nghĩa (3 hint/ô, vocab không rỗng, ô ≤2 dòng, có challenge đủ).
  3. ProgressController: id demo không có trong content bị bỏ qua (test: content không chứa `clean-text` → khởi động không lỗi).
  4. `content_json_test.dart` không còn phụ thuộc seed (round-trip trên testContent).
  5. `flutter analyze` sạch, `flutter test` xanh toàn bộ; số test giảm chỉ vì gộp seed_test/judge_contract_test (liệt kê test bị gộp/bỏ và lý do).
- **Validation command**: `cd mobile && flutter analyze && flutter test`
- **Evidence command**: `git status --porcelain -- mobile/`
- **Thứ tự thực hiện**: (1) fixture + contract test (vẫn chạy song song với seed); (2) chuyển test sang fixture; (3) xoá nội dung seed, đổi mặc định provider; (4) guard ProgressController.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`; không xoá test để cho xanh.
