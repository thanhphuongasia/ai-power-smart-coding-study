# T-04: JudgeClient (http) + Info.plist + contract test xuyên ngôn ngữ (mobile)

- **ID · tier · model**: T-04 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Client gọi `POST /run`, parse đúng hợp đồng, xử lý lỗi; test khoá INV-02/03 giữa seed Dart và `backend/app/exercises.json`.
- **Owned files**: `mobile/pubspec.yaml`, `mobile/pubspec.lock`, `mobile/ios/Runner/Info.plist`, `mobile/lib/data/judge_client.dart` (mới), `mobile/test/judge_client_test.dart` (mới), `mobile/test/judge_contract_test.dart` (mới)
- **Forbidden files**: `backend/**` (chỉ được ĐỌC exercises.json trong test), `planning/**`, mọi file mobile khác.
- **Acceptance criteria**:
  1. Thêm dependency `http` (bản ổn định hiện có, pin `^x.y.z`). API đúng `tasks/_shared.md` mục JudgeClient, gồm `judgeClientProvider` (Riverpod, như các provider khác trong app).
  2. Parse đủ field hợp đồng `/run` (PLAN.md). Mọi lỗi (SocketException/ClientException, timeout 20s, status ≠200, JSON hỏng, 404) → `JudgeResult(status: unavailable, unavailableReason: <câu tiếng Việt ngắn>)`, không ném exception ra ngoài.
  3. `judge_client_test.dart` dùng `MockClient` (`package:http/testing.dart`): passed, failed (actual null), error syntax có line, timeout, 503, mất mạng, JSON hỏng. Fixture JSON passed phải là bản chép NGUYÊN VĂN ví dụ trong PLAN.md mục hợp đồng (đã thay giá trị union bằng một giá trị cụ thể).
  4. `judge_contract_test.dart` đọc `File('../backend/app/exercises.json')` (test chạy với cwd = mobile/): tập id = tập id exercise trong seed (`uniqueExercises`); `function` = `functionName`; `mergeCells(exercise, {label: block.acceptedAnswers.first})` == `solution` từng ký tự.
  5. `Info.plist`: thêm `NSAppTransportSecurity` → `NSAllowsLocalNetworking = true` (chỉ cái này, không `NSAllowsArbitraryLoads`).
- **Validation command**: `cd mobile && flutter test test/judge_client_test.dart test/judge_contract_test.dart`
- **Evidence command**: `git status --porcelain -- mobile/pubspec.yaml mobile/pubspec.lock mobile/ios/Runner/Info.plist mobile/lib/data/judge_client.dart mobile/test/judge_client_test.dart mobile/test/judge_contract_test.dart`
- **Thứ tự thực hiện**: (1) contract test (rủi ro mối nối) chạy trước; (2) client + test; (3) Info.plist.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`; không sửa exercises.json hay seed — lệch thì BÁO, đừng tự sửa.
