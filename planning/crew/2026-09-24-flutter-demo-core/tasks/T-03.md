## API flutter_code_editor 0.3.5 đã xác minh từ source (~/.pub-cache/hosted/pub.dev/flutter_code_editor-0.3.5)
- `CodeController({String? text, Mode? language, EditorParams params = const EditorParams(), List<CodeModifier> modifiers = CodeController.defaultCodeModifiers, ...})`; ngôn ngữ: `import 'package:highlight/languages/python.dart'` → `python`.
- `EditorParams(tabSpaces: 4)` — mặc định là 2, PHẢI đặt 4.
- defaultCodeModifiers = IndentModifier, CloseBlockModifier, TabModifier, InsertionCodeModifier.{backticks,braces,brackets,doubleQuotes,parentheses}. Modifier CHỈ chạy khi `value` mới = text cũ + đúng 1 ký tự chèn tại con trỏ (xem `set value`, `_insertedLoc`). IndentModifier: '\n' giữ thụt dòng trước, +tabSpaces nếu ký tự cuối là ':'.
- InsertionCodeModifier KHÔNG có overtype: gõ `)` ngay trước `)` sẵn có → ra `))`. PHẢI tự xử lý: CodeModifier riêng cho `)` `]` `"` (và `'`): nếu ký tự ngay sau con trỏ là chính nó → chỉ dời con trỏ; `"`/`'` nếu không overtype thì chèn cặp. Truyền danh sách modifiers tùy biến (bỏ modifier mặc định trùng char — `_modifierMap` map theo char, cái sau đè cái trước).
- Popup gợi ý overlay có sẵn: tắt bằng subclass `CodeController` override `Future<void> generateSuggestions() async {}` (method public ở dòng ~815). Không để popup desktop hiện.
- Chèn text: `controller.value = TextEditingValue(...)`; `insertStr(String)` thay selection; `value.wordAtCursor`, `value.wordAtCursorStart` (extension trong src/code_field/text_editing_value.dart). Phím ký hiệu nên đi qua `value` với đúng 1 ký tự chèn để modifier (auto-close, indent) chạy giống gõ tay.
- `CodeField({required controller, focusNode, textStyle, gutterStyle, background, padding, onChanged, ...})` cần tổ tiên `CodeTheme(data: CodeThemeData(styles: ...), child: ...)`.

## Acceptance criteria
1. `suggest`: lấy từ đang gõ (chữ/số/_ liền trước con trỏ); lọc theo tiền tố không phân biệt hoa thường, bỏ từ trùng khớp y hệt từ đang gõ; xếp known > vocab > keyword, trong nhóm ưu tiên khớp chính xác hoa thường rồi ngắn hơn; bỏ trùng giữa các nhóm; tối đa `limit`.
2. Chưa gõ từ nào → gợi ý ngữ cảnh: dòng kết thúc bằng `for ` → `i` rồi known; kết thúc `in ` → `range(`, known; đầu dòng trống → known + `for`, `return`, `if`. Keyword/builtin Python: def return for in if elif else while range len append print True False None and or not.
3. `insertText` của builtin gọi hàm (range, len, print) có `(`; chạm gợi ý → thay đúng từ đang gõ, con trỏ ở cuối phần chèn; nếu insertText kết thúc `(` thì auto thêm `)` và con trỏ nằm giữa.
4. Hàng phím ký hiệu: ( ) [ ] : = . , " Tab. Chạm phím chèn tại con trỏ, không mất focus/bàn phím; Tab chèn 4 space.
5. Overtype `)` `]` `"` hoạt động (gõ tay `range(0, len(text), size)` với auto-close ra đúng một cặp ngoặc mỗi loại).
6. Enter sau `:` thụt 4; Enter thường giữ thụt dòng trước.
7. Thanh gợi ý + phím ký hiệu nằm DƯỚI editor, trên bàn phím (Column: editor Expanded/Flexible, rồi 2 hàng cuộn ngang cao ≥40 để dễ chạm); gọi `onChanged` mỗi lần text đổi và `onActivity` mỗi lần có tương tác.
8. Test engine (≥10 case: xếp hạng, ngữ cảnh for/in, trống, trùng, limit). Widget test: gõ `chu` → thấy `Key('suggestion-chunks')` → chạm → text `chunks`, con trỏ cuối; gõ `range` qua gợi ý → `range()` con trỏ giữa; overtype `)`; Enter sau `for i in x:` → dòng mới thụt 4; không có overlay popup. Widget test bọc `MaterialApp(theme: ThemeData.dark())` (không phụ thuộc T-02).
