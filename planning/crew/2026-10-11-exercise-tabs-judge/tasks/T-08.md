# T-08: ExerciseScreen (header + timer/idle + 3 tab) + tab Challenge + tab Solution + route (mobile)

- **ID · tier · model**: T-08 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Màn `/exercise/:id` mới theo mockup (artboard Main + Solution): header, TabBar Challenge / Code / Solution.
- **Owned files**: `mobile/lib/features/exercise/exercise_screen.dart` (mới), `mobile/lib/features/exercise/challenge_tab.dart` (mới), `mobile/lib/features/exercise/solution_tab.dart` (mới), `mobile/lib/features/exercise/code_tab.dart` (mới — CHỈ là stub `CodeTab({required Exercise exercise})` hiện chữ "Code", T-09 viết thật), `mobile/lib/app/router.dart`, `mobile/test/exercise_screen_test.dart` (mới)
- **Forbidden files**: `backend/**`, `planning/**`, mọi file khác (không xoá BlockList/Cell — việc của T-10; chỉ đổi route `/exercise/:id` sang ExerciseScreen, route block cũ để nguyên tới T-10).
- **Acceptance criteria**:
  1. Header: nút back, tên bài, dòng phụ `<file>.py · <functionName>`, pill đồng hồ (dùng `sessionProvider` như CellScreen hiện tại), hộp thoại idle/timeout giữ hành vi CellScreen (chép logic, cùng ngưỡng).
  2. TabBar 3 tab, tab Code có badge `<số ô có draft>/<tổng ô>`. Mặc định mở tab Challenge nếu chưa có draft, tab Code nếu đã có.
  3. Challenge: statement, khối "Dùng để làm gì?" (motivation), segmented "Ví dụ nhỏ" / "Dự án thật" (mặc định Dự án thật), danh sách ô cần viết (label + title), nút "Bắt đầu code" chuyển sang tab Code.
  4. Solution: cảnh báo "Ô nào đã xem lời giải sẽ không tính điểm..."; mỗi ô một thẻ, mặc định ẨN lời giải, nút "Hiện lời giải ô X" → gọi `viewSolution` rồi hiện code (font mono, highlight như editor) + explanation; ô đã xem trước đó hiện sẵn. Không có nút chép. Nút cuối "Quay lại tab Code để gõ".
  5. Bài bị khoá (`exerciseUnlockedProvider` false) mở thẳng qua route → hiện màn khoá + nút quay lại, không hiện tab (INV-08).
  6. Màu/typography dùng `context.palette` và token sẵn có (`lib/app/theme.dart`), không hardcode màu mới ngoài mockup (cell nền xám nhạt, tag vàng accent cho label).
  7. Test widget: tab chuyển được; Solution reveal gọi viewSolution và hiện code; bài khoá hiện màn khoá; layout không overflow ở 375×667 và 430×932.
- **Validation command**: `cd mobile && flutter test test/exercise_screen_test.dart && flutter analyze`
- **Evidence command**: `git status --porcelain -- mobile/lib/features/exercise/exercise_screen.dart mobile/lib/features/exercise/challenge_tab.dart mobile/lib/features/exercise/solution_tab.dart mobile/lib/features/exercise/code_tab.dart mobile/lib/app/router.dart mobile/test/exercise_screen_test.dart`
