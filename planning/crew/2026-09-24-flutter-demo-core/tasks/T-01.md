# T-01: Domain models + seed + answer checker

- ID · tier · model: T-01 · T2 · crew-impl-standard (sonnet)
- Objective: định nghĩa model nội dung, dữ liệu seed và bộ chấm đáp án theo INTERFACES.md.
- Owned files (dưới mobile/): lib/domain/models.dart, lib/data/seed.dart, lib/domain/answer_checker.dart, test/seed_test.dart, test/answer_checker_test.dart
- Forbidden: mọi file khác; pubspec.yaml; planning/**
- Acceptance criteria:
  1. Seed 3 theme: Semantic RAG system (`rag`), Document system, Twitter feed. RAG → topic Chunking (`rag-chunking`) → file chunker.py (`rag-chunker-py`) → `split-chunks` (5 block: def / chunks = [] / for+cắt 2 dòng / append hoặc gộp / return), `overlap-chunks`; thêm file preprocessor.py với 1 exercise đã xong hẳn. Theme khác có ≥1 topic, ≥1 exercise.
  2. `seedCompletedBlocks`: split-chunks = 2 (đang dở), exercise preprocessor = xong hẳn, còn lại 0.
  3. Test seed: mọi block ≤2 dòng mỗi đáp án; tổng số dòng đáp án đầu tiên của mỗi exercise ≤10; mỗi block đúng 3 hint; ID duy nhất toàn cục; mỗi block vocab không rỗng; block index 0 của mỗi exercise là dòng `def`.
  4. Đáp án block 3 của split-chunks chấp nhận `for i in range(0, len(text), size):` + dòng 2 `chunks.append(text[i:i + size])` (thụt thêm 4 so với dòng 1).
  5. normalizeCode: bỏ thụt nền chung (dedent), rstrip mỗi dòng, bỏ dòng trống, gộp khoảng trắng thừa, bỏ khoảng trắng quanh `( ) [ ] , : =` và toán tử, đổi `'` thành `"` — nhưng GIỮ thụt tương đối giữa các dòng (Python). Test: khác khoảng trắng/nháy → pass; sai tên hàm → fail; thiếu `:` → fail; thụt dòng 2 sai → fail.
  6. Code có ngoặc đóng thừa do auto-close (`range(0, len(text), size))`) → fail (không nuốt lỗi).
