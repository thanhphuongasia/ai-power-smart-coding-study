# T-05: Editor cho nhiều ô trên một màn + thanh công cụ dùng chung (mobile)

- **ID · tier · model**: T-05 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Cho phép đặt nhiều `CodeInput` trên cùng màn (mỗi ô TODO một editor) với MỘT thanh gợi ý + phím ký hiệu dùng chung, bám theo ô đang focus.
- **Owned files**: `mobile/lib/features/exercise/code_input.dart`, `mobile/test/code_input_test.dart`
- **Forbidden files**: `backend/**`, `planning/**`, mọi file mobile khác (cell_screen.dart vẫn dùng CodeInput như cũ và PHẢI chạy y nguyên).
- **Acceptance criteria**:
  1. Hành vi mặc định của `CodeInput` không đổi: mọi test cũ trong `code_input_test.dart` vẫn xanh không sửa assertion (chỉ được thêm test).
  2. `CodeInput` thêm tham số tuỳ chọn `bool showBars = true` và `String keyPrefix = 'code-input'` (key field/border dùng prefix này; mặc định giữ đúng key cũ `code-input-field`, `code-input-border`). Khi `showBars: false` editor không vẽ hai thanh.
  3. Widget mới public `CodeToolbar` (cùng file) vẽ thanh gợi ý + phím ký hiệu (+Tab) cho editor đang active, nhận đủ dữ liệu để gợi ý (`knownIdentifiers`, `vocab`) và một handle tới editor active. Bạn tự chọn cơ chế (vd `CodeInputHandle`/controller công khai), nhưng: bấm phím ký hiệu/gợi ý chèn vào ĐÚNG ô đang focus, không làm mất focus, không chèn vào ô khác; không có ô nào active thì thanh disable hoặc ẩn.
  4. Test mới: 2 `CodeInput(showBars:false, keyPrefix:'cell-A'/'cell-B')` + 1 `CodeToolbar` → focus ô B, bấm `(` → chỉ ô B nhận `()`; đổi focus sang A, bấm gợi ý → chèn vào A; key không trùng.
  5. Dartdoc ngắn cho API mới (tiếng Việt, như code hiện có).
- **Validation command**: `cd mobile && flutter test test/code_input_test.dart`
- **Evidence command**: `git diff --stat -- mobile/lib/features/exercise/code_input.dart mobile/test/code_input_test.dart`
- **Thứ tự thực hiện**: (1) tách logic bar ra `CodeToolbar` + handle, test multi-cell xanh; (2) đảm bảo CodeInput mặc định không đổi (chạy test cũ); (3) `flutter analyze`.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`.
