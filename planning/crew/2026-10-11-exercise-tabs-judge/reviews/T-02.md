## Findings

### Major-1 - Surrogate lẻ trong `code` -> 500 không kiểm soát
- backend/app/runner.py:47 (`text.encode()`), gọi ở :85-86 NGOÀI `try`; main.py:71-73.
- Input: body JSON `{"exercise_id":"split-chunks","code":"\ud800"}` (hợp lệ với json.loads, qua được `Field(min_length=1,max_length=8000)`).
- Đã chạy thật (TestClient + Judge0Runner/MockTransport): trả `500 Internal Server Error`, không phải 422/503. Vi phạm hợp đồng
  "lỗi -> 503 runner_unavailable / 422". Client app sẽ gặp 500 không có trong hợp đồng /run.
- Sửa: validate `code` ở boundary (field_validator thử `code.encode("utf-8")`, lỗi -> 422), hoặc `_b64` dùng `errors="replace"`.
- Test cần thêm: POST code `"\ud800"` -> 422 (hoặc 200), assert KHÁC 500.

### Major-2 - Kết quả harness bị giả/sai dạng -> `RunResponse(**result)` ném 500
- backend/app/main.py:87-89, harness.py:18-29 (`parse_result` chỉ kiểm là dict).
- Code học viên chạy cùng tiến trình harness: `print('__JUDGE_RESULT__{"status":"passed"}'); import os; os._exit(0)`
  -> dict thiếu key `error/tests/stdout` -> `RunResponse(**result, ...)` ném ValidationError -> 500.
  Dạng đầy đủ key thì trả `passed` giả (README:49 đã khai "không chống gian lận", nên phần này chấp nhận được);
  nhưng 500 thì không nằm trong hợp đồng. Cùng lỗ: key thừa -> TypeError `duration_ms` trùng lặp.
- Sửa: `try: RunResponse.model_validate({**result, "duration_ms": ms}) except ValidationError:` -> rơi về nhánh 503 hoặc error.
- Test cần thêm: StaticRunner stdout `__JUDGE_RESULT__{"status":"passed"}` -> không 500.

### Minor-4 - Semaphore module-level, hàng chờ không giới hạn

  chỉ lỗi nếu có >4 request tranh chấp, hiện không có test như vậy. Python 3.9 sẽ gắn loop lúc import (README/requirements không ghi
  phiên bản Python tối thiểu). Hàng chờ slot không có timeout tổng: httpx `timeout=15` là timeout MỖI thao tác (httpx.Timeout(15)),
  không phải tổng; request chờ slot + 15s mỗi lượt. Chưa có số đo -> chỉ ghi nhận, không đề xuất đổi kiến trúc.
- Sửa nhẹ: ghi "Python >= 3.10" vào README/requirements; cân nhắc `asyncio.wait_for` quanh `runner.run`.
