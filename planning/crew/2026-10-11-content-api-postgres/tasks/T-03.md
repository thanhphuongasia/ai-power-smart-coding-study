# T-03: Content index + fromJson/toJson + contentIndexProvider mặc định = seed (mobile)

- **ID · tier · model**: T-03 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Một đối tượng `Content` thay cho các hàm tra cứu toàn cục của seed, parse/xuất được JSON đúng hợp đồng `/content`, và một provider mà mọi nơi trong app sẽ đọc (tạm thời trả về seed hiện tại).
- **Owned files**: `mobile/lib/domain/models.dart`, `mobile/lib/domain/content.dart` (mới), `mobile/lib/data/content_providers.dart` (mới), `mobile/test/content_json_test.dart` (mới)
- **Forbidden files**: `backend/**`, `planning/**`, `mobile/lib/data/seed.dart` (chỉ đọc), mọi file khác. KHÔNG chuyển nơi đọc nào sang provider (T-04/T-05 làm).
- **Acceptance criteria**:
  1. API đúng `tasks/_shared.md`. Các helper của `Content` cho kết quả GIỐNG HỆT hàm cùng tên trong seed.dart (exerciseById, locateExercise, uniqueExercises, locateFilesNamed) với `Content(themes: seedThemes)` — test so từng hàm.
  2. `fromJson`/`toJson` cho mọi model, key snake_case đúng hợp đồng (PLAN.md). `Example.note` nullable. Model vẫn `const` constructor như cũ (thêm factory, không phá chỗ gọi cũ).
  3. Round-trip: `Content.fromJson(jsonDecode(jsonEncode(seedContent.toJson())))` bằng seed về mọi field (viết so sánh sâu trong test, vì model không có `==`). Bài dùng chung (split-chunks ở 2 file) sau fromJson là CÙNG một instance (`identical`).
  4. fromJson báo `FormatException` rõ ràng khi: file trỏ tới exercise id không có; thiếu field bắt buộc; sai kiểu.
  5. `toJson` KHÔNG sinh key `judge`.
  6. `contentIndexProvider` (Provider<Content>) mặc định `Content(version: 'seed', themes: seedThemes)`.
- **Validation command**: `cd mobile && flutter test test/content_json_test.dart && flutter analyze`
- **Evidence command**: `git status --porcelain -- mobile/lib/domain/models.dart mobile/lib/domain/content.dart mobile/lib/data/content_providers.dart mobile/test/content_json_test.dart`
- **Thứ tự thực hiện**: (1) Content index + test so với seed; (2) fromJson/toJson + round-trip; (3) lỗi FormatException; (4) provider.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`.
