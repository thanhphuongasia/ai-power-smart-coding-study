# T-03: Model mới + merge.dart + chuyển 5 bài sang dạng template/ô TODO (mobile)

- **ID · tier · model**: T-03 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Thêm Challenge/Example/template/label/explanation vào model, viết `merge.dart`, viết lại nội dung 5 bài trong seed theo dạng mới (code nhập ngắn nhất).
- **Owned files**: `mobile/lib/domain/models.dart`, `mobile/lib/domain/merge.dart` (mới), `mobile/lib/data/seed.dart`, `mobile/test/seed_test.dart`, `mobile/test/merge_test.dart` (mới)
- **Forbidden files**: `backend/**`, `planning/**`, mọi file mobile khác (kể cả screen, session_controller, các test khác — test khác đỏ vì đổi số block là CHẤP NHẬN, ghi danh sách vào báo cáo).
- **Acceptance criteria**:
  1. Model đúng `tasks/_shared.md` mục "Dart model". Thay đổi model chỉ THÊM field, không xoá/đổi tên field cũ (để code cũ vẫn compile). `flutter analyze` không có error mới.
  2. `merge.dart` đúng chữ ký trong `_shared.md`. Marker: dòng khớp `^(\s*)# TODO ([A-Z])\s*$`. `mergeCells`: ô được đổi tab→4 space, bỏ dòng trống đầu/cuối, dedent chung, thêm thụt lề của marker vào từng dòng; `lineOrigin.length == số dòng code`; code nối "\n", không newline cuối. Thiếu key của một ô → ném `ArgumentError` (UI sẽ chặn Run khi ô trống).
  3. `merge_test.dart`: ghép lời giải split-chunks ra đúng chuỗi trong `_shared.md`; ô 2 dòng giữ thụt tương đối; ô có tab/dòng trống thừa; lineOrigin đúng từng dòng; `templateSegments` của split-chunks = [Locked(2 dòng), Todo A, Todo B, Todo C].
  4. Seed 5 bài theo mục "Chia ô" của `_shared.md`: template + blocks (label A/B/C, id dạng `<exercise-id>-a`, indentLevel khớp marker, acceptedAnswers.first = lời giải ô, explanation 1–2 câu tiếng Việt, 3 hint, vocab). `functionName`/`params` giữ nguyên.
  5. `challenge` mỗi bài: statement (1–2 câu), motivation (ứng dụng thật, 1–2 câu), `small` example và `project` example (bối cảnh dự án thật: RAG/HR handbook, hệ thống tài liệu, mạng xã hội...). `input`/`output` là code Python gọi hàm và kết quả — output PHẢI lấy bằng cách chạy `python3` thật trên lời giải tham chiếu. split-chunks dùng đúng ví dụ mockup: small `split_chunks("hello world", 4)` → `['hell', 'o wo', 'rld']`; project = handbook text ở `tasks/T-01.md` mục 6, size 30.
  6. Thêm `final Set<String> seedPassedExercises = {'clean-text'};` và `final Map<String, Map<String, String>> seedDrafts = {'split-chunks': {'A': 'for i in range(0, len(text), size):'}};`. GIỮ `seedCompletedBlocks` (T-06 sẽ xoá) nhưng chỉnh số cho khớp số block mới (split-chunks 0, clean-text = số block của nó).
  7. `seed_test.dart` cập nhật luật: bỏ luật "block 0 là def"; thêm luật INV-01 (mỗi block có đúng một marker `# TODO <label>` trong template, indent marker = 4 × indentLevel, không marker thừa); ghép lời giải mọi bài ra code compile được về mặt thụt lề (so với chuỗi trong `_shared.md` cho cả 5 bài); mỗi ô ≤2 dòng.
- **Validation command**: `cd mobile && flutter test test/seed_test.dart test/merge_test.dart`
- **Evidence command**: `git status --porcelain -- mobile/lib/domain mobile/lib/data/seed.dart mobile/test/seed_test.dart mobile/test/merge_test.dart`
- **Thứ tự thực hiện**: (1) model + merge.dart + merge_test xanh; (2) chuyển seed + seed_test; (3) `flutter analyze` và liệt kê test khác đang đỏ.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`; không sửa file ngoài Owned dù test khác đỏ.
