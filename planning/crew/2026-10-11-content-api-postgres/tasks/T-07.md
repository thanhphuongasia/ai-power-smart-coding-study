# T-07: ContentRepository (GET /content + cache shared_preferences) + contentProvider async (mobile)

- **ID · tier · model**: T-07 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Lớp tải nội dung từ server có cache offline, và một AsyncNotifier giữ trạng thái tải. CHƯA gắn vào app (T-08), CHƯA đổi mặc định `contentIndexProvider` (T-09).
- **Owned files**: `mobile/pubspec.yaml`, `mobile/pubspec.lock`, `mobile/lib/data/content_repository.dart` (mới), `mobile/lib/data/content_providers.dart`, `mobile/lib/data/judge_client.dart` (CHỈ đổi nguồn base URL sang hàm dùng chung), `mobile/test/content_repository_test.dart` (mới)
- **Forbidden files**: `backend/**`, `planning/**`, mọi file khác.
- **Acceptance criteria**:
  1. Thêm `shared_preferences` (bản ổn định, pin `^x.y.z`). Hàm `Uri apiBaseUrl()` trong content_repository.dart đọc `const String.fromEnvironment('API_URL', defaultValue: 'http://127.0.0.1:8000')`; `judge_client.dart` dùng hàm này thay cho `JUDGE_URL` (một biến cho một server — ghi dartdoc).
  2. `ContentRepository({http.Client? httpClient, Uri? baseUrl, Future<SharedPreferences> Function()? prefs, Duration timeout = const Duration(seconds: 5)})` với `Future<ContentLoad> load()`:
     - `ContentLoad { Content content; ContentSource source /* network | cache */; }`.
     - Mạng 200 + `Content.fromJson` OK → ghi cache (chuỗi JSON thô + version) → `source: network`.
     - Mạng lỗi/timeout/≠200/JSON hỏng → đọc cache; cache hợp lệ → `source: cache`; cache hỏng → xoá cache, coi như không có.
     - Không có gì → ném `ContentUnavailable(reason)` (câu tiếng Việt ngắn).
     - Không bao giờ ghi đè cache tốt bằng dữ liệu hỏng (INV-08).
  3. `content_providers.dart`: thêm `contentRepositoryProvider` và `contentProvider` = `AsyncNotifierProvider<ContentController, ContentLoad>` (build gọi `load()`; `Future<void> refresh()` tải lại, giữ dữ liệu cũ trong lúc tải). `contentIndexProvider` GIỮ NGUYÊN mặc định seed.
  4. Test (`MockClient` + `SharedPreferences.setMockInitialValues`): online → network + cache được ghi; offline có cache → cache; offline không cache → ContentUnavailable; server trả JSON hỏng có cache → cache cũ (không bị ghi đè); cache hỏng + offline → ContentUnavailable và cache bị xoá; online sau khi đã có cache cũ → version mới được ghi (INV-08); `refresh()` đổi từ cache sang network.
  5. Toàn suite xanh.
- **Validation command**: `cd mobile && flutter test test/content_repository_test.dart && flutter analyze && flutter test`
- **Evidence command**: `git status --porcelain -- mobile/`
- **Thứ tự thực hiện**: (1) repository + test lỗi/cache; (2) provider; (3) judge_client base URL.
- **Cấm**: không "tiêm lỗi tạm"; không `git checkout --`/`git stash`; không `dart format` thư mục.
