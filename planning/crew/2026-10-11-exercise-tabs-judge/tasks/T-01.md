# T-01: Harness chấm bài + dữ liệu test 5 bài (backend)

- **ID · tier · model**: T-01 · T2 · `crew-impl-standard` (sonnet, balanced)
- **Objective**: Viết chương trình harness độc lập máy chấm (đọc stdin JSON, chạy code học viên, chạy test case, in một dòng kết quả JSON) + file dữ liệu test của 5 bài.
- **Owned files**: `backend/requirements.txt`, `backend/.gitignore`, `backend/app/__init__.py`, `backend/app/harness.py`, `backend/app/exercises.json`, `backend/tests/test_harness.py`
- **Forbidden files**: `mobile/**`, `planning/**`, mọi file `backend/` khác (runner.py, main.py thuộc T-02).
- **Acceptance criteria**:
  1. `harness.py` là chương trình chạy bằng `python3 harness.py < payload.json`. stdin = `{"code": str, "function": str, "cases": [...]}`. Chỉ dùng thư viện chuẩn, tương thích Python **3.12** (không dùng cú pháp/API mới hơn).
  2. Compile code học viên bằng `compile(code, "solution.py", "exec")`, exec trong namespace riêng. SyntaxError → `error = {"kind": "syntax", "line": e.lineno, "message": ...}`; exception khi exec hoặc khi gọi hàm → `kind: "runtime"`, `line` = dòng sâu nhất trong traceback có filename `solution.py` (None nếu không có). Không tìm thấy hàm → runtime error, line None, message nói rõ tên hàm.
  3. Case: `{"args": [...], "expect": {"return": v}}` so giá trị trả về; `{"args": [...], "expect": {"arg": i, "value": v}}` so tham số thứ i SAU khi gọi. Gọi với `copy.deepcopy(args)`. `call` = `f"{function}({', '.join(map(repr, args))})"` (args gốc), `expected`/`actual` = `repr()`. Exception trong một case → case đó `actual: null, passed: false` và set `error` runtime (dừng các case sau cũng được — ghi rõ chọn gì).
  4. `print` của học viên được gom (redirect stdout) vào field `stdout` (cắt 4000 ký tự), KHÔNG lẫn vào dòng kết quả. Dòng kết quả in ra stdout thật, một dòng duy nhất, tiền tố hằng `RESULT_PREFIX = "__JUDGE_RESULT__"` + JSON: `{"status": "passed"|"failed"|"error", "error": ..., "tests": [...], "stdout": str}`. `status`: error nếu có `error`, failed nếu có case fail, passed nếu tất cả pass. (timeout và duration_ms do backend thêm, không phải harness.)
  5. Có hàm thuần `parse_result(stdout: str) -> dict | None` trong harness.py để backend tìm dòng có tiền tố (lấy dòng CUỐI có tiền tố).
  6. `exercises.json`: object key = exercise id, value = `{"function": str, "solution": str, "cases": [...]}`; `solution` khớp TỪNG KÝ TỰ với `tasks/_shared.md`. Mỗi bài ≥3 case, có case biên (chuỗi rỗng, đoạn cuối ngắn hơn size, overlap...). split-chunks bắt buộc có: `("hello world", 4)` → `['hell', 'o wo', 'rld']`, `("", 3)` → `[]`, và một case "dự án thật": text `"Nhân viên được nghỉ phép 12 ngày/năm. Phép chưa dùng hết được cộng dồn sang quý 1 năm sau."`, size 30. Mọi expected lấy bằng cách CHẠY `python3` thật trên lời giải tham chiếu, không tự viết tay.
  7. `test_harness.py` (pytest) chạy harness như subprocess thật (`sys.executable harness.py`, stdin JSON): mọi bài với lời giải tham chiếu → passed; thiếu `return` → failed với actual `'None'`; SyntaxError ở dòng 4 → line 4; exception ở dòng 3 → line 3; `print` trong code học viên không phá kết quả; case kiểu `arg` (save-document, like-post) đúng.
  8. `requirements.txt` có `fastapi`, `uvicorn[standard]`, `httpx`, `pytest` (pin bản cụ thể bạn cài được). `.gitignore` có `.venv/`, `__pycache__/`, `.env`, `.pytest_cache/`. Tạo venv: `cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`.
- **Validation command**: `cd backend && .venv/bin/python -m pytest -q tests/test_harness.py`
- **Evidence command**: `git status --porcelain -- backend/`
- **Thứ tự thực hiện**: (1) harness + test lỗi syntax/runtime/số dòng/print, chạy xanh; (2) mới tới exercises.json + test 5 lời giải; (3) requirements/gitignore.
- **Cấm**: không "tiêm lỗi tạm" vào file nào; không `git checkout --`/`git stash`; ghi "không rõ" không bị coi là thiếu — bịa mới là lỗi.
